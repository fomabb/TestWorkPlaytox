# Account Transfer Application

Простое консольное приложение на Java, демонстрирующее потокобезопасные переводы средств между несколькими счетами в многопоточной среде. Проект выполнен в рамках тестового задания.

## Основные технологии и библиотеки

-   **Java SE 17**: Язык программирования и основная платформа.
-   **Maven**: Система сборки и управления зависимостями.
-   **Log4j 2**: Библиотека для логирования всех операций.
-   **JUnit 5 & AssertJ**: Фреймворки для написания юнит-тестов.

Проект намеренно не использует фреймворки вроде Spring, чтобы продемонстрировать понимание фундаментальных концепций Java Core, в частности `java.util.concurrent`.

## Ключевые особенности реализации

-   **Многопоточность**: Используется `ExecutorService` для управления пулом рабочих потоков, выполняющих транзакции.
-   **Потокобезопасность**: Доступ к счетам синхронизируется с помощью `java.util.concurrent.locks.ReentrantLock`.
-   **Защита от Deadlock**: Реализован механизм захвата блокировок в строгом порядке (по ID счетов), что предотвращает взаимные блокировки потоков.
-   **Атомарность**: Счетчик транзакций использует `java.util.concurrent.atomic.AtomicInteger` для безопасного инкремента из разных потоков.
-   **Логирование**: Все транзакции (успешные, неудачные, отмененные), а также ошибки и ключевые события жизненного цикла приложения, логируются в консоль и в файл `logs/transactions.log`.

## Как запустить проект

### Требования

-   **JDK 17** или выше.
-   **Apache Maven** 3.6.0 или выше.

### Шаг 1: Сборка проекта

1.  Склонируйте репозиторий:
    ```bash
    git clone https://github.com/fomabb/TestWorkPlaytox.git
    cd TestWorkPlaytox
    ```

2.  Соберите проект с помощью Maven. Эта команда скачает все зависимости и скомпилирует исходный код.
    ```bash
    mvn clean install
    ```

### Шаг 2: Запуск приложения

После успешной сборки приложение можно запустить из командной строки.

```bash
java -jar target/account-transfer-app-1.0.0.jar
```

Приложение начнет свою работу. Вы увидите логи в консоли в реальном времени. После выполнения 30 транзакций приложение автоматически завершится и выведет в консоль результат финальной проверки целостности данных.

### Шаг 3: Просмотр логов

Все логи также дублируются в файл, который создается в корневой папке проекта:
`./logs/transactions.log`

Этот файл содержит полную историю всех операций, выполненных за время работы приложения.

## Запуск тестов

Проект содержит набор юнит-тестов, которые проверяют корректность бизнес-логики, включая тест на потокобезопасность при конкурентных переводах.

Для запуска тестов выполните команду:

```bash
mvn test
```

## Конфигурация

Основные параметры приложения (количество счетов, потоков, транзакций) можно изменить в константах класса `com.playtox.transfer.App`.

```java
public class Main {
    private static final int ACCOUNT_COUNT = 4;
    private static final int INITIAL_MONEY = 10000;
    private static final int THREAD_COUNT = 2;
    private static final int MAX_TRANSACTIONS = 30;
    // ...
}
```
